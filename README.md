# Canal continuo de Colab

Esta rama publica únicamente el catálogo del actualizador. El código se obtiene del commit inmutable indicado, tras verificar sus hashes y CI. No contiene memoria, credenciales ni snapshots. Las próximas versiones se publican aumentando la secuencia de releases/colab-channel.json; el usuario mantiene el mismo cuaderno. La primera publicación es candidata, con aplicación automática deshabilitada.
