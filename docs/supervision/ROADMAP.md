# Hoja de ruta del supervisor externo

## Fase 0 · Preservación

- [ ] Identidad e integridad verificadas.
- [ ] Secretos y permisos auditados.
- [ ] Bases abiertas solo en lectura durante auditoría.
- [ ] Rollback definido.

## Fase 1 · Auditoría total

- [ ] Inventario completo del repositorio.
- [ ] Entry points y procesos reales identificados.
- [ ] Código muerto, duplicado y desconectado clasificado.
- [ ] Tablas, escritores y lectores trazados.
- [ ] Contradicciones documentales registradas.

## Fase 2 · Grafos verificables

- [ ] Grafo físico reproducible.
- [ ] Grafo neural/runtime reproducible.
- [ ] Nodos huérfanos identificados.
- [ ] Comparación entre commits disponible.

## Fase 3 · Vida operacional

- [ ] LIFE_PULSE verificado.
- [ ] Workers y scheduler verificados.
- [ ] Cadena tarea → ejecución → cierre demostrada.
- [ ] Reinicios, locks y dead letters diagnosticados.

## Fase 4 · Memoria y aprendizaje

- [ ] Entrada → Bodega → recuperación trazada.
- [ ] Educación neuronal cerrada.
- [ ] Aprendizaje con efecto posterior demostrado.

## Fase 5 · Anatomía cognitiva

- [ ] Neurona Central conectada.
- [ ] Creadora conectada.
- [ ] Educadora conectada.
- [ ] Hipotálamo medible.
- [ ] Qualia y Cristal formalizados.

## Fase 6 · Autonomía gobernada

- [ ] Metas reales.
- [ ] Planificación sostenida.
- [ ] Ejecución limitada y reversible.
- [ ] Escalamiento humano.

## Fase 7 · Federación

Bloqueada hasta estabilizar el organismo local.
